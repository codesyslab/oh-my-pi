ШПАРГАЛКА — собрать новый omp
=============================

Репо: /home/codesyslab/data/sysprojects/oh-my-pi
Ветка: main → origin/main (codesyslab/oh-my-pi)
omp на системе: ~/.local/bin/omp → packages/coding-agent/dist/omp

------------------------------------------------------------
1. Один раз при первом клоне / после смены Rust-крейтов:
------------------------------------------------------------
    bun setup
        # bun install + build:native + coding-agent link + ~/.bun/bin/omp

------------------------------------------------------------
2. После правок в TS:
------------------------------------------------------------
    cd /home/codesyslab/data/sysprojects/oh-my-pi
    bun --cwd=packages/coding-agent run build
        # пересобирает packages/coding-agent/dist/omp
        # ~/.local/bin/omp — это симлинк на него, обновится сам

------------------------------------------------------------
3. После правок в Rust (crates/*, packages/natives):
------------------------------------------------------------
    cd /home/codesyslab/data/sysprojects/oh-my-pi
    bun run build:native
    bun --cwd=packages/coding-agent run build

------------------------------------------------------------
4. Проверить что свежая версия жива:
------------------------------------------------------------
    omp --version          # omp/18.1.12
    omp --smoke-test       # smoke-test: ok
    omp stats --summary    # дашборд

------------------------------------------------------------
5. Только правки TS, без пересборки (dev-режим):
------------------------------------------------------------
    omp ...                # через ~/.bun/bin/omp → bun src/cli.ts
                            # подхватывает сорсы напрямую

------------------------------------------------------------
6. Пуш в main от codesyslab:
------------------------------------------------------------
    git add .
    git commit -m "..."
    git push origin main   # идёт через keyring-токен codesyslab

------------------------------------------------------------
7. Апгрейд bun (если package.json поднял версию):
------------------------------------------------------------
    bun upgrade
    bun --version          # проверяем что ≥ требуемой
    bun setup              # пересоберёт нативный аддон под новый bun

------------------------------------------------------------
Подсказка: путь к корню репо и собранному бинарю
------------------------------------------------------------
    /home/codesyslab/data/sysprojects/oh-my-pi/packages/coding-agent/dist/omp
    /home/codesyslab/.local/bin/omp  (симлинк — обновляется при пересборке)
